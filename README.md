# Nausheen's Travel Atlas

An interactive, responsive travel planner for round trips from Hyderabad to Thailand or Kerala.

## Features

- Selectable 5, 7, and 10-day itineraries
- Medium and luxury budget estimates
- Flight routing, hotels, food, local transport, rules, and emergency contacts
- Interactive packing and sightseeing checklists saved in the browser
- Seasonal guidance based on departure date
- Print and Save as PDF support

The site is a buildless static application. Open `index.html` directly or serve the repository with any static web server.
